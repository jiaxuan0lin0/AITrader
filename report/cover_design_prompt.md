# 封面设计 Prompt

请为一份中文课程实验报告设计 A4 竖版封面，风格参考 Apple 产品白皮书、金融科技研究报告和高端数据产品说明书，整体简约、克制、留白充足。

## 报告信息

标题：
基于深度学习的股票趋势预测与模拟交易实验报告

副标题：
多源因子建模 · 横截面排序 · Top20 组合策略

项目名：
AItrader / MSGCA

小组成员：
待填写

课程项目：
股票趋势预测与模拟交易

## 视觉要求

- 中文为主，保留必要英文专有名词，如 AItrader、MSGCA、Top20。
- 不要出现日期、归档目录、运行配置、checkpoint、代码路径等工程信息。
- 不要做营销海报，不要科技蓝大渐变，不要赛博风，不要密集金融 K 线背景。
- 版面应有明显留白，标题层级清晰，信息量少而精。
- 色彩以黑、深灰、浅灰为主，可加入极少量低饱和蓝色作为强调。
- 可设计一个抽象图标或小型视觉元素，用于表达：
  - 多源数据融合；
  - 横截面排序；
  - Top20 组合；
  - 注意力/门控模型。
- 图形应抽象、几何、轻量，例如细线、点阵、极简柱形、节点连接、排序轨迹等。
- 不要使用真实股票 K 线截图、真实公司 logo、交易软件界面或复杂背景图。
- 封面要适合嵌入 LaTeX 报告，优先输出可复刻的 SVG/PDF 矢量设计。

## 版式建议

- A4 竖版，四周留白 28-36mm。
- 顶部左侧放项目标识：AItrader / MSGCA。
- 中上区域放大标题，标题最多两行，字重较粗。
- 标题下方放副标题，使用较浅灰色。
- 中部或右中部放一个极简抽象图形，不抢标题。
- 底部放小组成员与课程项目，字号小，灰色，使用细分割线。

## 输出内容

请输出：

1. 一张封面设计图。
2. 若可以，额外输出 SVG 或 PDF 矢量版本。
3. 简短说明所用颜色、字体层级和图形含义。
